# 학원맞춤키트 주문 시스템 (프로토타입)

## 폴더 구성
```
academy-kit-order/
├─ index.html          ← 주문 페이지 (이 파일만 열어도 로컬에서 바로 동작)
├─ assets/
│  ├─ master.pdf        ← 실제 64p 마스터 브로슈어 (선택한 페이지를 여기서 잘라 이어붙입니다)
│  └─ thumbs/pg-01.jpg ~ pg-64.jpg  ← 선택 화면용 페이지 미리보기 이미지
└─ README.md
```

## 지금 되는 것
- 카테고리(챕터)별로 실제 페이지 썸네일을 보면서 필요한 페이지만 체크
- 표지 문구(1p), 학원명·로고(3p) 입력 → 브라우저에서 실제 PDF에 합성
- "PDF 생성하기" → 선택한 페이지만 진짜로 이어붙인 인쇄용 PDF를 미리보기 + 다운로드
- 서버 업로드 없이 전부 브라우저(JS)에서 처리됩니다 (pdf-lib 사용)

## 아직 안 되는 것 (다음 단계)
1. **인쇄업체 웹하드로 자동 발송** — 지금은 다운로드 후 직접 첨부해서 보내야 합니다.
   EmailJS 같은 서비스를 붙이면 자동화할 수 있어요. 계정 만들고 Service ID·Template ID·Public Key만
   알려주시면 `index.html`의 발송 버튼에 연결해드립니다.
2. **고등부시험대비 · 수능올케어 · 모바일보고서 페이지** — 이번 마스터 PDF(64p)에는 포함되어 있지 않아
   선택 목록에 없습니다. 해당 페이지를 디자인해서 `assets/master.pdf`에 추가하면 목록에 넣을 수 있습니다.
3. **표지/로고 합성 좌표** — 지금은 1p(표지 문구), 3p(학원명+로고) 위치에 임의로 좌표를 잡아뒀습니다.
   실제 디자인 좌표와 다르면 미세 조정이 필요합니다. "PDF 생성하기"로 나온 결과를 보고 위치를 알려주시면
   `index.html` 안의 `drawText`/`drawImage` 좌표 값만 조정하면 됩니다.

## 깃허브 페이지로 배포하는 방법
1. 이 폴더(`academy-kit-order`) 전체를 원하시는 깃허브 저장소에 그대로 커밋 & 푸시합니다.
   (저는 저장소에 직접 접근할 수 없어서, 이 폴더를 그대로 올려주시면 됩니다.)
2. 저장소 Settings → Pages → Source를 "Deploy from a branch"로 설정하고,
   이 폴더가 저장소 루트라면 branch를 `main` / `/(root)`로 지정합니다.
   (만약 리포에 다른 파일도 같이 있다면, 이 폴더를 `docs/` 등 하위 폴더로 두고 Pages 소스를
   그 폴더로 지정하면 됩니다.)
3. 몇 분 후 `https://<계정명>.github.io/<저장소명>/` 주소로 접속하면 바로 동작합니다.

## 참고
- `assets/master.pdf`가 약 15MB라 첫 로딩이 느릴 수 있습니다. 추후 이미지 압축을 더 하면 줄일 수 있어요.
- 한글 폰트는 매번 온라인에서 (Noto Sans KR, jsdelivr CDN) 불러옵니다. 오프라인 환경에서는 동작하지 않습니다.
