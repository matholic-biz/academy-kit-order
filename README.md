# 학원맞춤키트 주문 시스템 (프로토타입)

## 폴더 구성
```
academy-kit-order/
├─ index.html          ← 주문 페이지 (학원맞춤키트 / 현판 주문 / 웰컴키트 주문 탭)
├─ admin.html           ← 관리자 페이지 (비밀번호로 신청내역 조회)
├─ assets/
│  ├─ master.pdf         ← 실제 64p 마스터 브로슈어 (선택한 페이지를 여기서 잘라 이어붙입니다)
│  ├─ thumbs/pg-01.jpg ~ pg-64.jpg  ← 선택 화면용 페이지 미리보기 이미지
│  ├─ guide-video.mp4    ← 상단 "사용 가이드 보기" 버튼에서 재생되는 안내 영상
│  ├─ covers/            ← 표지 디자인 실제 이미지 (frame-1, compass-1~3, essence-1~2)
│  └─ signboard/          ← 현판 디자인 이미지 (sign-luxury-gold.png)
├─ google-apps-script/
│  └─ Code.gs            ← 이메일 자동 발송 + 신청내역 시트 기록용 구글 앱스 스크립트
└─ README.md
```

## 지금 되는 것
- 상단 탭으로 세 가지 신청 종류 구분: **학원맞춤키트 / 현판 주문 / 웰컴키트 주문**
- **학원맞춤키트**: 표지 컨셉 3종(THE FRAME 1종 / COMPASS 3종 / THE ESSENCE 2종, 실제 디자인 이미지 적용) 선택 → 카테고리별 페이지 체크 → 학원 정보·표지 문구 입력 → PDF 생성·미리보기·다운로드 → (설정 시) 인쇄업체 이메일 자동 발송
- **현판 주문 / 웰컴키트 주문**: 디자인 확인 후 문구·수량·담당자 정보만 입력하면 PDF 없이 바로 접수 이메일 발송
- 상단 "▶ 사용 가이드 보기" 버튼 → 신청 방법 안내 영상을 팝업으로 재생
- 모든 신청(학원맞춤키트/현판/웰컴키트)은 (설정 시) 구글 시트에 자동으로 한 줄씩 기록되고, `admin.html`에서 비밀번호로 신청내역을 조회할 수 있습니다
- 서버 업로드 없이 전부 브라우저(JS)에서 처리됩니다 (pdf-lib 사용)

## 표지 디자인 안내
- THE FRAME: 대각선 분할 디자인 1종 (frame-1)
- COMPASS: 막대 패턴 디자인 3종 (compass-1~3)
- THE ESSENCE: 방사형 글로우 · 단색 디자인 2종 (essence-1~2)

디자인을 선택하면 PDF 생성 시 표지(1p) 전체에 실제 이미지가 배경으로 합성되고, 그 위에 입력하신 표지 문구가 얹힙니다.

## 사용 가이드 영상 넣기
`academy-guide-hyperframes` 프로젝트에서 내보낸(Export) mp4 파일을 그대로 이 폴더의 `assets/guide-video.mp4`라는 이름으로 넣어주시면 됩니다. (파일명이 정확히 `guide-video.mp4`여야 합니다.)

## 이메일 자동 발송 + 신청내역 시트 기록 설정
1. https://script.google.com 접속 (회사 구글/Gmail 계정 로그인) → 새 프로젝트 생성
2. `google-apps-script/Code.gs` 내용 전체를 복사해서 붙여넣기
3. 코드 상단의 값들을 실제 값으로 수정
   - `PRINT_VENDOR_EMAIL`: 실제 인쇄업체 이메일
   - `SHARED_SECRET`: 그대로 두거나 바꾸면 `index.html`/`admin.html`의 같은 값도 동일하게 맞추기
   - `LOG_SHEET_ID`: 아래 "신청내역 시트 만들기" 참고
   - `ADMIN_PASSWORD`: 관리자만 아는 비밀번호로 변경
4. 저장 → 우측 상단 "배포" → "새 배포" → 유형: 웹 앱
   - 실행 계정: 나(Me)
   - 액세스 권한이 있는 사용자: 모든 사용자(Anyone)
   → 배포 → 처음 실행 시 권한 승인 팝업 허용
5. 배포 완료 후 나오는 웹 앱 URL을 복사
6. `index.html`과 `admin.html` 양쪽의 `GAS_WEBHOOK_URL` 값에 그 URL을 붙여넣기
7. 저장 후 다시 배포(또는 커밋 & 푸시)

**이미 배포한 적이 있다면**: "새 배포"를 또 만들면 URL이 바뀝니다. 대신 "배포 관리"에서 기존 배포를 선택하고 연필(수정) 아이콘 → 버전을 "새 버전"으로 바꾸고 배포하면, URL은 그대로 유지된 채 코드만 최신화됩니다.

### 신청내역 시트 만들기
1. https://sheets.google.com 에서 새 스프레드시트를 만듭니다 (이름은 자유).
2. 주소창 URL에서 `.../spreadsheets/d/` 뒤와 `/edit` 앞 사이의 긴 문자열을 복사합니다. 이것이 시트 ID입니다.
3. `Code.gs`의 `LOG_SHEET_ID`에 붙여넣고 재배포합니다.
4. 이후 신청이 들어올 때마다 "신청내역"이라는 시트 탭이 자동으로 만들어지고 한 줄씩 기록됩니다.

### 관리자 페이지 사용법
1. `admin.html`을 열고, `Code.gs`에 설정한 `ADMIN_PASSWORD`를 입력합니다.
2. 신청내역이 표로 보이고, 상단 탭으로 유형별(학원맞춤키트/현판/웰컴키트) 필터링이 가능합니다.
3. "새로고침" 버튼으로 최신 신청내역을 다시 불러올 수 있습니다.

**주의**: 배포 시 "모든 사용자" 접근을 허용하므로, 코드 안 `SHARED_SECRET`(신청 접수용)과 `ADMIN_PASSWORD`(조회용)로 각각 접근을 제한합니다. 개인 Gmail 계정은 하루 발송 가능 메일 수(약 100통)에 제한이 있고, 첨부파일은 약 25MB까지 가능합니다.

## 아직 안 되는 것 (다음 단계)
1. **고등부시험대비 · 수능올케어 · 모바일보고서 페이지** — 이번 마스터 PDF(64p)에는 포함되어 있지 않아
   선택 목록에 없습니다. 해당 페이지를 디자인해서 `assets/master.pdf`에 추가하면 목록에 넣을 수 있습니다.
2. **표지/로고 합성 좌표** — 지금은 1p(표지 문구), 3p(학원명+로고) 위치에 임의로 좌표를 잡아뒀습니다.
   실제 디자인 좌표와 다르면 미세 조정이 필요합니다. "PDF 생성하기"로 나온 결과를 보고 위치를 알려주시면
   `index.html` 안의 `drawText`/`drawImage` 좌표 값만 조정하면 됩니다.
3. **웰컴키트 디자인 이미지** — 아직 실제 구성 이미지가 없어 안내 문구만 표시됩니다. 디자인이 나오면 넣어드릴게요.

## 깃허브 페이지로 배포하는 방법
1. 이 폴더(`academy-kit-order`) 전체를 원하시는 깃허브 저장소에 그대로 커밋 & 푸시합니다.
2. 저장소 Settings → Pages → Source를 "Deploy from a branch"로 설정하고,
   이 폴더가 저장소 루트라면 branch를 `main` / `/(root)`로 지정합니다.
3. 몇 분 후 `https://<계정명>.github.io/<저장소명>/` 주소로 접속하면 바로 동작하고,
   `https://<계정명>.github.io/<저장소명>/admin.html` 로 관리자 페이지에 접속할 수 있습니다.

## 참고
- `assets/master.pdf`가 약 15MB라 첫 로딩이 느릴 수 있습니다.
- 한글 폰트는 매번 온라인에서 (Noto Sans KR, jsdelivr CDN) 불러옵니다. 오프라인 환경에서는 동작하지 않습니다.
- `admin.html`은 비밀번호로만 보호되며, URL을 아는 사람이 비밀번호까지 알면 볼 수 있는 수준의 보안입니다. 민감한 개인정보가 많다면 추후 더 강한 인증으로 교체를 권장합니다.
