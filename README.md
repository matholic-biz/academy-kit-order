# 학원맞춤키트 주문 시스템 (프로토타입)

## 폴더 구성
```
academy-kit-order/
├─ index.html          ← 주문 페이지 (학원맞춤키트 / 현판 주문 / 웰컴키트 주문 탭)
├─ admin.html           ← 관리자 페이지 (비밀번호로 신청내역 조회)
├─ assets/
│  ├─ pages/              ← 실제 조립용 페이지 이미지. 표지 내지·뒷표지(cover_1_2a/3a/4a, cover_(2~6)_2b/3b/4b) 포함 (아래 "페이지 구성" 참고)
│  ├─ covers/              ← 앞표지 6종 원본 (cover-1.jpg ~ cover-6.jpg)
│  ├─ thumbs/              ← 화면 미리보기 이미지 (topic_1.png~topic_12.png, why-1.jpg, profile-1.jpg 등)
│  ├─ templates/          ← 추천 템플릿 A형/B형 목업·펼친면 이미지 (아래 "추천 템플릿" 참고)
│  ├─ signboard/          ← 현판 디자인 이미지 (sign-luxury-gold.png)
│  ├─ welcome/            ← 웰컴키트 구성 이미지 (welcome-kit.png)
│  └─ fonts/              ← 표지·학원명 문구용 SUIT 폰트 (Regular/Light/Medium/SemiBold)
├─ google-apps-script/
│  └─ Code.gs            ← 이메일 자동 발송 + 신청내역 시트 기록용 구글 앱스 스크립트
└─ README.md
```

## 지금 되는 것
- 상단 탭으로 세 가지 신청 종류 구분: **우리학원브랜드북 / 현판 주문 / 웰컴키트 주문** (웰컴키트 탭은 주소에 `?welcome=1`이 있어야 보입니다)
- **우리학원브랜드북**: (1단계) 맨 위에서 **[추천 템플릿으로 빠르게 구성] / [맞춤형으로 직접 구성]** 두 카드 중 하나를 먼저 선택하면 해당 내용만 펼쳐집니다.
  - 추천 템플릿: A형/B형 카드에서 펼친면을 미리 보고 "이 템플릿 선택" 버튼으로 선택
  - 맞춤형 구성: 표지 디자인 6종 선택 + 주제별 구성 12개 중 전체 분량 20p 이상 되도록 선택 (주제 썸네일을 누르면 그 주제의 실제 페이지를 모달로 미리 볼 수 있습니다)
  → (2단계) 주문 정보(학원 정보·표지문구·소개문구·인사말·원장님 사진·로고) 입력 → (3단계) PDF 미리보기 생성 → 인쇄업체 이메일 자동 발송
- **현판 주문 / 웰컴키트 주문**: 디자인 확인 후 문구·수량·담당자 정보만 입력하면 PDF 없이 바로 접수 이메일 발송
- 우측 하단 "신청이 처음이신가요?" 배너 → 누르면 실제 신청 화면 위에 스포트라이트(글로우 링)와 말풍선으로 표지·공통구성 확인부터 발송까지 단계별로 안내하는 인터랙티브 온보딩 투어가 시작됩니다 (동영상 대신 실제 화면을 그대로 따라가며 배우는 방식). 배너는 ×로 닫을 수 있고, 닫으면 같은 세션 동안에는 다시 뜨지 않습니다 (새로고침하면 다시 보입니다).
- 모든 신청은 (설정 시) 구글 시트에 자동으로 한 줄씩 기록되고, `admin.html`에서 비밀번호로 신청내역을 조회할 수 있습니다
- 서버 업로드 없이 전부 브라우저(JS)에서 처리됩니다 (pdf-lib 사용)
- 신청 완료 후 "처음으로" 버튼(또는 상단 좌측 로고 클릭)으로 새로고침하여 다음 신청자가 바로 이어서 쓸 수 있습니다
- 모바일(휴대폰) 화면(600px 이하)에서는 표지/공통구성 제목이 썸네일 위로 올라가고, 가이드·주제별 구성 썸네일이 더 적은 열로 재배치되며, 이전/다음 버튼이 꽉 차게 바뀌는 등 별도 반응형 레이아웃이 적용됩니다

## 페이지 구성 (우리학원브랜드북)
최종 PDF는 아래 순서로 조립됩니다. 괄호 안은 페이지 수입니다.

1. 앞표지 (1P) — 6종 디자인 중 선택. 표지 문구(학원명·슬로건)가 들어갑니다
2. 앞표지 내지 = 원장님 프로필 (1P) — 학원명("{학원명} BRANDBOOK")과 공통 고정 태그라인 문구, 원장님 프로필 사진(주문정보에서 올린 사진 재사용)이 들어갑니다. 표지1 전용 버전과 표지2~6 공용 버전, 두 가지가 있고 선택한 표지 디자인에 따라 자동으로 정해집니다 (아래 "표지 디자인 안내" 참고)
3. 우리학원은 이렇게 다릅니다 (1P) — 고객이 직접 작성한 소개 문구와 로고가 들어갑니다
4. 인사말 (2P) — 고객이 직접 작성한 인사말 문구와 학원장님 프로필 사진이 첫 페이지에 들어갑니다
5. 좋은 수학학원 고르는 법 (7P)
6. 주제별 구성 — 아래 12개 중 전체 분량(표지+공통구성+주제별)이 20p 이상 되도록 고객이 선택 (선택된 것만, 항상 1~12번 순서로 배치). 평가·유형분석·문제풀이클리닉·내신시험대비·고등부시험대비·학습통합보고서(1·3·5·7·8·10번)에는 "추천" 뱃지가 표시됩니다. 썸네일(이미지)을 누르면 그 주제의 주제명·페이지수·전체 페이지(내지)·내용을 보여주는 모달이 뜹니다 (아래 "주제별 구성 미리보기 모달" 참고). 카드의 나머지 영역(제목 등)을 누르면 선택/해제됩니다.
   1) 진단 (5P)
   2) 교재채점 (2P)
   3) 유형분석 (6P)
   4) 동영상클리닉 (4P)
   5) 문제풀이클리닉 (5P)
   6) 시험대비플로우 (4P)
   7) 내신대비 (6P)
   8) 고등시험대비 (2P)
   9) AI학습지원 (4P)
   10) 학습통합보고서 (3P)
   11) 모바일보고서 (3P)
   12) 수학경시대회 (4P)
7. 뒤표지 내지 · 뒷표지 (2P) — 표지1 전용 또는 표지2~6 공용 버전이 **PDF 맨 마지막**에 붙습니다

(표지 세트는 앞표지 1장 + 앞표지내지·뒤표지내지·뒷표지 공용 3장, 총 4장입니다. "구성 선택" 화면에서는 6종 앞표지 중 하나를 고르기만 하면 위 순서로 자동 배치됩니다.)

### 페이지 이미지 파일명 규칙
`assets/pages/`에 아래 이름으로 PNG 파일을 넣어주세요 (실제 조립용, 문구 들어갈 자리는 비워둔 원본). **앞표지 6장만 예외적으로 `assets/covers/` 폴더에 JPG로 넣어주세요** (아래 참고).

- 앞표지: `assets/covers/cover-1.jpg` ~ `cover-6.jpg` (6종, 표지 1~6번에 대응, JPG, 업로드 완료)
- 앞표지 내지(=원장님 프로필)·뒤표지 내지·뒷표지: 표지 1 전용 버전과 표지 2~6 공용 버전, 이렇게 2세트만 있으면 됩니다 (업로드 완료, `assets/pages/`에 PNG)
  - 표지 1 전용: `cover_1_2a.png`(앞표지 내지=프로필), `cover_1_3a.png`(뒤표지 내지), `cover_1_4a.png`(뒷표지)
  - 표지 2~6 공용: `cover_(2~6)_2b.png`(앞표지 내지=프로필), `cover_(2~6)_3b.png`(뒤표지 내지), `cover_(2~6)_4b.png`(뒷표지) — 파일명에 괄호와 물결표(`~`)가 그대로 들어갑니다
  - `index.html`의 `COVERS` 배열 안 `variant` 값(`cover1` 또는 `shared`)으로 디자인별로 어느 세트를 쓸지 바꿀 수 있습니다
  - 뒤표지 내지는 뒷표지 바로 앞에 오는 페이지이고, 두 이미지가 서로 붙은 "펼침면" 한 장짜리 파일이 아니라 각각 낱장(단일 페이지) 이미지로 나눠서 넣어주셔야 합니다
- 우리학원은 이렇게 다릅니다: `why_1.png` (1장, 업로드 완료)
- 인사말: `greeting_1.png`, `greeting_2.png` (업로드 완료)
- 좋은 수학학원 고르는 법: `guide_1.png` ~ `guide_7.png` (업로드 완료)
- 주제별 구성 내지(실제 페이지): `topic_1_1.png` ~ `topic_1_5.png`(주제1), `topic_2_1.png`~`topic_2_2.png`(주제2), ... 주제 번호(1~12, 0을 붙이지 않음)와 해당 주제의 페이지 수(아래 "페이지 구성" 목록 참고)만큼 순서대로. 모달 미리보기와 PDF 조립에 그대로 쓰입니다. 주제 1/2/6/8/9/10/11/12는 파일이 모두 맞게 올라와 있고, 아래 주제만 아직 확인이 필요합니다.
  - 주제3(6p): `topic_3_6.png`이 없습니다 (1~5만 업로드됨)
  - 주제4(4p): `topic_4_2.png`, `topic_4_4.png`가 없습니다 (1, 3만 업로드됨)
  - 주제5(5p): `topic_5_2.png` 대신 `topic_5-2.png`(하이픈)로 올라가 있습니다 — 언더스코어로 이름만 바꿔주시면 나머지(1/3/4/5)와 함께 정상 인식됩니다
  - 주제7(6p): `topic_7_1.png`만 없고 2/3/4/5/6은 업로드됐습니다
- 주제별 구성 그리드 썸네일(대표 이미지): **`assets/thumbs/topic_1.png` ~ `topic_12.png`** (페이지 번호 없이 주제 번호만, thumbs 폴더, PNG, 12개 모두 업로드 완료) — 내지(`assets/pages/topic_N_1.png` 등)와는 폴더도 파일도 별도입니다.

`assets/thumbs/`에는 `why-1.jpg`, `greeting-1/2.jpg`, `guide-1~7.jpg`, `profile-1.jpg`처럼 하이픈 규칙의 JPG를 넣으면 화면 미리보기로 쓰입니다. `profile-1.jpg`는 "원장님 프로필" 미리보기 카드(1장짜리 대표 이미지)에 쓰입니다 — 실제 조립되는 앞표지 내지 파일(`cover_1_2a.png`/`cover_(2~6)_2b.png`)과는 별개의, 화면 확인용 대표 이미지입니다. 다만 **앞표지는 `assets/covers/`, 표지 내지·뒷표지와 주제별 구성은 `assets/pages/`의 원본을 그대로 불러와 캔버스로 축소**하므로, 이 둘은 `assets/thumbs/`에 따로 넣을 필요가 없습니다.

파일이 없으면 PDF 생성 시 어떤 파일이 없는지 오류 메시지로 알려드리고, 화면 미리보기는 빈 회색 박스로 표시됩니다.

## 표지 디자인 안내
- 표지는 6종 앞표지 디자인 중 하나를 고르면, 앞표지내지(=원장님 프로필)·뒤표지내지·뒷표지가 선택한 디자인에 맞춰(표지1은 전용 세트, 표지2~6은 공용 세트) 자동으로 정해집니다. 화면에는 뒤표지내지·뒷표지를 별도로 미리 보여주는 카드는 없지만("표지 내지 · 뒷표지" 카드는 삭제했습니다), PDF 조립 시에는 그대로 자동 반영됩니다. 다만 앞표지 내지(=원장님 프로필)만은 "표지" 바로 아래에 `assets/thumbs/profile-1.jpg` 대표 이미지로 미리보기 카드를 다시 보여줍니다 (선택 항목은 아니고, 페이지 수에도 별도로 더해지지 않습니다 — 이미 표지 세트에 포함된 페이지를 눈으로 확인하는 용도입니다).
- 실제 PDF에서는 앞표지 → 앞표지 내지(원장님 프로필) → (본문) → 뒤표지 내지 → 뒷표지 순서로 배치됩니다. 뒤표지 내지·뒷표지는 항상 PDF의 맨 마지막 두 페이지입니다.
- 앞표지에는 고객이 입력한 표지 문구(비워두면 학원명)가 디자인별로 정해진 위치·크기·폰트·자간·색상으로 얹힙니다. (`index.html`의 `COVERS` 배열 안 각 디자인의 `title` 값에서 위치/크기/색상 조정 가능)
- 표지 원본 이미지는 인쇄용 고해상도라 작은 썸네일로 줄이면 문구가 흐려 보일 수 있어, 화면에서는 캔버스로 한 번 더 고품질 축소해서 보여주고(`sharpenCoverThumbs()`), 마우스를 올리면 2.1배로 확대해 또렷하게 확인할 수 있습니다. 이 마우스오버 확대는 표지뿐 아니라 다릅니다·인사말·가이드(공통 구성)와 주제별 구성 썸네일에도 동일하게 적용됩니다 (`zoom-thumb` CSS 클래스).
- 앞표지 내지(=원장님 프로필, 1P)의 제목·태그라인·사진은 `PROFILE_TITLE_SPEC` / `PROFILE_TAGLINE_SPEC` / `PROFILE_PHOTO_SPEC` 값에 따라 배치됩니다. **다만 앞표지내지 샘플 이미지를 보니 이미 문구(로고+태그라인)가 디자인에 포함된 것처럼 보입니다 — 이 경우 텍스트를 덧그리면 겹쳐 보일 수 있으니, 확정된 파일을 주시면 겹치는지 확인하고 필요하면 이 오버레이 자체를 빼드리겠습니다.**
  - 제목은 `"{학원명} BRANDBOOK"` 형태로 자동 조합됩니다 (학원명은 주문정보 1번째 입력값을 그대로 사용, 별도 입력칸 없음).
  - 태그라인은 모든 학원 공통 고정 문구(`PROFILE_TAGLINE_TEXT`)입니다. 학원마다 다르게 하고 싶으시면 이 문구를 직접 편집하거나, 말씀해주시면 주문정보에 입력칸을 추가해드릴 수 있습니다.
  - 사진은 주문정보에서 올리는 학원장님 프로필 사진(인사말 페이지와 같은 파일)을 그대로 재사용합니다. 별도 업로드는 필요 없습니다.
- 우리학원은 이렇게 다릅니다(1P)의 소개 문구·로고는 `WHY_TEXT_SPEC` / `WHY_LOGO_SPEC` 값에 따라 배치됩니다.
- 인사말(2P)의 인사말 문구·학원장님 프로필 사진은 `GREETING_TEXT_SPEC` / `GREETING_PHOTO_SPEC` 값에 따라 배치됩니다.
- **현재 `COVERS`/`COVER_VARIANT_SETS`/`PROFILE_TITLE_SPEC`/`PROFILE_TAGLINE_SPEC`/`PROFILE_PHOTO_SPEC`/`WHY_TEXT_SPEC`/`GREETING_TEXT_SPEC`/`GREETING_PHOTO_SPEC`의 좌표는 전부 임시값입니다.** 실제 디자인 파일을 넣어주시고 "PDF 미리보기 생성하기" 결과를 캡처해서 보내주시면, 이전에 표지 9종에 했던 것처럼 정확한 픽셀 좌표로 다시 맞춰드립니다.

표지 문구는 SUIT 폰트(Regular/Light/Medium/SemiBold)를 사용하며, `assets/fonts/` 폴더에 해당 폰트 파일들이 있어야 PDF 생성이 정상 동작합니다.

## 주제별 구성 미리보기 모달
"맞춤형으로 직접 구성" 화면의 주제별 구성 그리드에서 각 카드의 썸네일 이미지를 누르면 모달이 뜨고, 다음을 보여줍니다.
- 주제명 (번호 포함) + 전체 페이지 수
- 좌우 화살표로 넘겨보는 내지(실제 페이지) 캐러셀, 하단에 페이지 위치를 나타내는 점(dot) 표시
- 내용(설명 문구) — `index.html`의 `TOPICS` 배열 각 항목의 `desc` 값입니다. 질문형 문구 목록으로 채워져 있고, 줄바꿈 그대로 모달에 표시됩니다. 문구를 더 다듬고 싶으시면 `desc` 값만 수정해주시면 됩니다.

카드에서 썸네일 이미지가 아닌 나머지 영역(제목 등)을 누르면 기존처럼 그 주제가 선택/해제됩니다 (미리보기와 선택은 서로 다른 동작입니다).

## 추천 템플릿 (A형/B형)
"추천 템플릿으로 빠르게 구성" 카드를 선택하면 추천 템플릿 2종(A형/B형) 카드가 나타나고, 각 카드의 "펼친면 미리보기" 버튼을 누르면
라이트박스가 열리며 [HEYZINE](https://heyzine.com) 플립북(실제 책장 넘기는 애니메이션)이 임베드되어 표시됩니다. "이 템플릿 선택" 버튼을 누르면 해당 카드가 선택 표시되고
[다음] 버튼이 활성화됩니다.

**설정 방법**
1. 템플릿 A형/B형 각각의 교재(또는 펼친면 스프레드 모음)를 PDF로 준비합니다.
2. HEYZINE에 로그인 후 해당 PDF를 업로드해 플립북을 만듭니다.
3. HEYZINE 편집 화면 → Share/Embed → "Embed code"에 나오는 `<iframe>`의 `src` 주소만 복사합니다.
4. `index.html`의 `RECOMMENDED_TEMPLATES` 배열에서 해당 템플릿의 `heyzineUrl` 값에 붙여넣습니다.
   ```js
   { id:'a', name:'추천 템플릿 A형', mockup:'assets/templates/template-a.png',
     heyzineUrl:'https://heyzine.com/flip-book/xxxxxxxxx.html' }
   ```

`heyzineUrl`이 비어 있으면 "펼친면 미리보기 준비 중" 안내 문구만 표시되고, 값을 넣는 즉시 실제 플립북으로 바뀝니다.
카드에 보이는 3D 목업 이미지는 `assets/templates/template-a.png` / `template-b.png` 파일로 업로드 완료되어 바로 반영됩니다.
HEYZINE 무료 플랜은 워터마크/트래픽 제한이 있을 수 있으니, 실제 운영 전에 요금제를 확인해 주세요.

템플릿 이름은 같은 배열의 `name` 값에서 수정할 수 있습니다 (설명 문구는 사용하지 않아 카드에서 뺐습니다). **"이 템플릿 선택"으로 템플릿을 골라도 실제 표지·주제 선택에는 아직 반영되지 않습니다** — 어떤 표지 디자인·어떤 주제 구성(20p 이상)으로
구성되는지 알려주시면, 선택 즉시 그 구성이 실제로 적용되도록 연결해드리겠습니다. 그 전까지는 템플릿 선택 시 표지 1번·주제 미선택 상태로 다음 단계에 진행되니, 2단계(주문 정보) 이전에 확인이 필요합니다.

## 신청 방법 온보딩 투어 안내
우측 하단 배너(또는 배너를 닫았다면 다시 열 방법이 없으므로, 필요하면 코드에서 `startTour()`를 호출하는 버튼을 추가해주세요)를 누르면
실제 신청 화면 위에 스포트라이트(초록 테두리)와 말풍선이 나타나 구성 방법 선택(맞춤형 구성 안내) → 표지 선택 → 공통 구성 확인(다릅니다·인사말·가이드) →
주제별 구성 선택 → 정보 입력 → PDF 생성/발송까지 총 12단계로 안내합니다. 별도 영상 파일이 필요 없으며, 안내 문구는 `index.html`의 `TOUR_STEPS` 배열에서
수정할 수 있습니다 (각 단계의 `title`/`desc`, 대상 요소는 `target`/`clickTarget`). 배너 문구·디자인은 `.tour-banner` 관련 CSS와
HTML(`id="tourBanner"`)에서 수정할 수 있습니다.

## 이메일 자동 발송 + 신청내역 시트 기록 설정
1. https://script.google.com 접속 (회사 구글/Gmail 계정 로그인) → 새 프로젝트 생성
2. `google-apps-script/Code.gs` 내용 전체를 복사해서 붙여넣기
3. 코드 상단의 값들을 실제 값으로 수정
   - `PRINT_VENDOR_EMAIL`: 실제 인쇄업체 이메일
   - `SHARED_SECRET`: 그대로 두거나 바꾸면 `index.html`/`admin.html`의 같은 값도 동일하게 맞추기
   - `LOG_SHEET_ID`: 아래 "신청내역 시트 만들기" 참고
   - `ADMIN_PASSWORD`: 관리자만 아는 비밀번호로 변경
4. 저장 → 우측 상단 "배포" → "새 배포" → 유형: 웹 앱
   - 실행 계정: 나(Me)
   - 액세스 권한이 있는 사용자: 모든 사용자(Anyone)
   → 배포 → 처음 실행 시 권한 승인 팝업 허용
5. 배포 완료 후 나오는 웹 앱 URL을 복사
6. `index.html`과 `admin.html` 양쪽의 `GAS_WEBHOOK_URL` 값에 그 URL을 붙여넣기
7. 저장 후 다시 배포(또는 커밋 & 푸시)

**이미 배포한 적이 있다면**: "새 배포"를 또 만들면 URL이 바뀝니다. 대신 "배포 관리"에서 기존 배포를 선택하고 연필(수정) 아이콘 → 버전을 "새 버전"으로 바꾸고 배포하면, URL은 그대로 유지된 채 코드만 최신화됩니다.

### 신청내역 시트 만들기
1. https://sheets.google.com 에서 새 스프레드시트를 만듭니다 (이름은 자유).
2. 주소창 URL에서 `.../spreadsheets/d/` 뒤와 `/edit` 앞 사이의 긴 문자열을 복사합니다. 이것이 시트 ID입니다.
3. `Code.gs`의 `LOG_SHEET_ID`에 붙여넣고 재배포합니다.
4. 이후 신청이 들어올 때마다 "신청내역"이라는 시트 탭이 자동으로 만들어지고 한 줄씩 기록됩니다.

### 관리자 페이지 사용법
1. `admin.html`을 열고, `Code.gs`에 설정한 `ADMIN_PASSWORD`를 입력합니다.
2. 신청내역이 표로 보이고, 상단 탭으로 유형별(학원맞춤키트/현판/웰컴키트) 필터링이 가능합니다.
3. "새로고침" 버튼으로 최신 신청내역을 다시 불러올 수 있습니다.

**주의**: 배포 시 "모든 사용자" 접근을 허용하므로, 코드 안 `SHARED_SECRET`(신청 접수용)과 `ADMIN_PASSWORD`(조회용)로 각각 접근을 제한합니다. 개인 Gmail 계정은 하루 발송 가능 메일 수(약 100통)에 제한이 있고, 첨부파일은 약 25MB까지 가능합니다.

## 참고
- 페이지 이미지가 많아지면 첫 PDF 생성 시 다운로드 시간이 걸릴 수 있습니다.
- 표지·학원명 문구 폰트(SUIT)는 `assets/fonts/`에서 불러오므로 오프라인에서도 문제없습니다.
- `admin.html`은 비밀번호로만 보호되며, URL을 아는 사람이 비밀번호까지 알면 볼 수 있는 수준의 보안입니다. 민감한 개인정보가 많다면 추후 더 강한 인증으로 교체를 권장합니다.
